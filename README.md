# 一人教研组 · DSH 学习系统套件

装上它，DSH 里会多一个「总规划」岗位：它替你把一周排开、给每科下发本周最小任务；你按学科再开几个伴学会话，各自把自己的进度写进文件。

进度不在聊天记录里，在文件里——所以关掉窗口不会丢，换会话也能接上。

---

## 一、安装（一次性，约 2 分钟）

1. 打开 DSH → 侧边栏 **插件** → **添加插件**
2. 粘贴**本目录的绝对路径**（例如 `D:\dsh-study-kit`）
3. 点安装 → 完成后**完全退出 DSH 再打开**（不是只关窗口）
4. 新建会话，预设选择器里出现 **「总规划」**

需要 DSH `>= 0.2.2-rc.1`。不需要 npm，不需要构建，没有第三方依赖。

> 安装后如果选择器里看不到「总规划」，先确认 DSH 真的完全退出了（任务管理器里没有残留进程），再打开。

---

## 二、第一次：建档（约 10 分钟）

新建会话，选 **「总规划」**，把工作目录指向你打算放学习资料的文件夹（例如 `D:\学习`）。

它会把六个问题**一次问完**：作息、目标、学校进度、科目、设备、每天可用时间。

回答完，它写出三个文件：

```
总规划.md      长期目标 + 本周硬约束 + 周看板
周日程表.md    固定节奏（起床/课/训练/睡），不排具体任务
变更记录.md    改了什么（广播给所有会话）
```

**建档只问一次。** 之后任何会话都不会再问；只有你明确说「重新建档」才会重来。

---

## 三、之后：按学科开课

一个科目 = 一个目录 = 一个会话。

1. **先建目录**（在 PowerShell 里，把 `D:\学习` 换成你的学习根）：

   ```powershell
   node new-subject.mjs 数学 --outline --root "D:\学习"
   ```

   它会建 `D:\学习\数学\学习档案.md`（和空骨架的 `复习提纲.md`），**先校验再落盘**，写不进去会回滚。

2. **再建一个学科岗位**（只做一次，用 DSH 的「创造模式」会话），把这句粘进去：

   > 按本机 `@local/dsh-study` 的规范，给我建一个「数学伴学」预设：挂 `study-suite` 的 `companion` 与 `judge` 部件；会话工作目录是 `D:\学习\数学`；每轮读该目录的 `学习档案.md` 与 `本周任务.md`；学员要答案时直接给，不要提示阶梯。

   规范原文在 `specs\`：`会话规范.md`（persona 必须具备哪几段）、`记忆规范.md`（档案写不下时怎么取舍）、`文件规范.md`（每份文件谁写、多大）、`建岗规程.md`（建岗步骤与验收）。建岗时让它先读这几份。

   创造模式会写入 profile 的预设声明，**重启 DSH 后**选择器里就有「数学伴学」。化学、英语同理，只是换个名字。

3. **开课**：新建会话选「数学伴学」，工作目录 `D:\学习\数学`。第一句可以说「带我过一遍这门课的进度」，它会建 `课程路线.md`、`复习提纲.md`。

## 四、常见问题

**选择器里没有「总规划」**
装完必须**完全退出** DSH 再打开。还不行就看插件页里本包是否显示已启用。

**它又问那六个问题**
说明当前工作目录下没有 `总规划.md`——多半是新会话的目录选错了。检查工作目录是不是指到了学习根。

**学科会话不注入档案**
工作目录要指到**科目目录**（`D:\学习\数学`），不是学习根本身。

**档案写不进去**
`学习档案.md` 上限 6144 B / 60 行。会话里说一句「整理一下」，让它把旧内容收拢。
