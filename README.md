# 一人教研组 · DSH 学习系统套件

装上它，DSH 里会多一个「总规划」岗位：它替你把一周排开、给每科下发本周的最小任务。进度不在聊天记录里，在文件里——关掉窗口不会丢，换会话也能接上。

---

## 一、安装

1. 打开 DSH → 侧边栏 **插件** → **添加插件**
2. 粘贴仓库地址：`https://github.com/via103/dsh-study-kit`
3. 点安装 → **完全退出 DSH 再打开**

需要 DSH `>= 0.2.2-rc.1`，机器上能访问 GitHub 并装了 Git。

> 拉不下来就用 ZIP：仓库首页 → 绿色 **Code** → **Download ZIP** → 解压 → 在「添加插件」里粘解压出来那一层目录（`package.json` 所在的那层）。

---

## 二、开始使用

1. **建一个文件夹**当学习根，例如 `D:\学习`。
2. **新建「总规划」会话**，工作目录指到这个文件夹，把你的情况说一遍：作息、目标、学校进度、科目、设备、每天可用时间。它写出 `总规划.md`、`周日程表.md`、`变更记录.md`。
3. **新建「创造模式」会话**，说：

   > 先读本包的 `specs\建岗规程.md`（不知道包在哪，就找 `~/.dsh/profiles/*/node_modules/@local/dsh-study`），再按它建一个「数学伴学」预设：工作目录 `D:\学习\数学`；每轮读该目录的 `学习档案.md` 与 `本周任务.md`；我要答案时直接给，不要提示阶梯。

   新开会话时，预设里就有「数学伴学」。
4. **开课**：建文件夹 `D:\学习\数学`，新建会话选「数学伴学」，工作目录指到这个文件夹，说「建一下这门课的档案」，然后即可使用。

包里只带「总规划」；如果需要添加学科，就照第 3、4 步再来一遍。

---

## 三、常见问题

**选择器里没有「总规划」**
装完必须**完全退出** DSH 再打开。

**它又问那六个问题**
说明工作目录下没有 `总规划.md`，多半是新会话的目录选错了。

**学科会话不注入档案**
工作目录要指到**科目文件夹**（`D:\学习\数学`），不是学习根本身。

**档案写不进去**
`学习档案.md` 上限 6144 B / 60 行，说一句「整理一下」让它收拢。

**创造模式说找不到 specs**
给它绝对路径：`%USERPROFILE%\.dsh\profiles\<profile>\node_modules\@local\dsh-study\specs`（`<profile>` 通常是 `desktop`）。还不行就跳过——按第 3 步那句话直接建，岗位能用，只是少了规范里的细节。
