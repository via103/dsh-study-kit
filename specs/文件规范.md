# 文件规范

每科一个目录，目录里这几份文件各司其职。名字是约定的，改名或换位置，注入与写守护都会失效。

| 文件 | 谁写 | 谁读 | 内容 | 上限 | 每轮注入 |
|---|---|---|---|---|---|
| `学习档案.md` | 该科自己 | 该科 + 总规划（只读） | 状态、卡点、薄弱点 | 6144 B / 60 行 | 是 |
| `本周任务.md` | 总规划 | 该科（只能勾选） | 本周最小必做，≤3 条 | 2048 B | 是 |
| `变更记录.md` | 总规划（学习根） | 全部科目 | 改了什么，一条一行 | 1024 B / 10 条 | 是 |
| `课程路线.md` | 该科自己 | 该科 | 单元表 + 证据 + 下一课 | 无（摘要注入） | 摘要 |
| `复习提纲.md` | 该科自己 | 该科 | 一行一条知识点，带日期 | 无 | 否，按需读 |
| `题目记录.md` | 该科自己 | 该科 | 按日期分节的题与结果 | 无 | 否，按需读 |
| `易错清单.md` | 该科自己（数学等） | 该科 | 按日期记错因与反复项 | 无 | 否，按需读 |

## 三条铁律

1. **一个文件一个写者**：档案只有该科能写，总规划只读；别科代改会让漂移检测失真。
2. **任务只能勾选**：`本周任务.md` 的正文由总规划写，科目只能把 `- [ ]` 改成 `- [x]`，不能改任务文字。
3. **改动要留痕**：改计划、下发任务、改基准，都由总规划追加一条到 `变更记录.md`；它不是任务清单，不放复选框。

## 为什么有上限

上限不是为了扩容，是**强迫精简**。写不下时按 `记忆规范.md` 整理，不要靠删末尾或删最旧。

## 格式约定

- 日期一律 `MM-DD`，年份在标题里写一次；跨年另起标题。
- **一条一行、一条一处**：`复习提纲.md` 每条 ≤120 字，只写「结论 + 触发条件」；过程细节（题解步骤、命令、报错原文）进 `题目记录.md`，提纲里留一句指针。
- **写前先查重**：落盘前 `grep` 一次目标文件，已有同类就并进那一行——重复条目会让一次检索命中三段。
- 学习日以**凌晨 4 点**为界，4 点前算前一天。
